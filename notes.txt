/:id -> path parameters
   accessed via req.params
   returns object 
   /:123 -> {id: "123"}

/?param=val -> query parameters
   accessed via req.query
   returns object
   /?foo=bar -> {foo : "bar"}

🫱🏻‍🫲🏼 CORS (Cross-Origin Resourse Sharing)

    🔥Example:
      🧑‍💻 Frontend: http://localhost:5173
      🥷 Backend: http://localhost:5001
